## 👨🏾‍💻 About Me

Hi, I'm **Patrick Straton Mbabazi**, a **Computer Engineering student at the University of Rwanda** and a **software developer from Rwanda**.

I enjoy building practical software systems and solving real-world problems through technology. My main focus is **backend development, software engineering, databases, APIs, cybersecurity, cloud computing, artificial intelligence, machine learning, networking, and data analysis**.

I work across the stack, with a stronger focus on **backend systems and APIs**, while also building web and mobile applications. I enjoy learning how systems work from the database and API layer all the way to the user interface.

I have experience working with **Python, FastAPI, Django, Node.js, NestJS, React, TypeScript, PostgreSQL, MongoDB, Docker, Redis, Celery, Flutter, and machine learning technologies**.

I am also interested in **cybersecurity, cloud computing, computer networking, IoT, GIS, and distributed systems**.

## 🚀 Featured Projects

### 🎫 ServiceDesk

An internal IT service management and ticketing system designed to handle support requests, ticket assignment, priorities, SLAs, notifications and attachments.

**Tech:** FastAPI • PostgreSQL • Redis • Celery • React • TypeScript • Docker

### 🥕 VegetableHub

A farm management and mapping platform designed around agricultural data, farm tracking and geographical information.

**Tech:** Django • REST API • PostgreSQL • React • Flutter • GIS • OpenStreetMap

### 🤖 Carrot Quality Classification

A computer vision project for classifying carrots into **GOOD** and **BAD** quality categories for agricultural sorting.

**Tech:** Python • PyTorch • Transfer Learning • ResNet18 • VGG16 • MobileNetV2 • EfficientNet • DenseNet

### 🔵 Arduino BLE Projects

Exploring Bluetooth Low Energy communication between Arduino devices and central devices, including remote LED control.

**Tech:** Arduino • C++ • Bluetooth Low Energy • IoT
